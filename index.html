What is Boba Drops?

Boba Drops is the first workshop we will be doing at FHS Hack Club. In this workshop students will be able to design their very own simple HTML and CSS websites. They will submit these to Hack Club to be reviewed, and once accpeted students will get BOBA!!!



What are the requirements for your website?

  • It must be a website that you build YOURSELF! (You cannot copy others or use AI)
  • You have to use at least 5 HTML & CSS features, and only HTML and CSS allowed. Make sure to include at least 1 image.
  • Show that you actually tried. So put in some effort and make sure your site is accessible, so no tiny fonts, excessive color clashes, or illegible text.
